## 1. 框架定位与使命 (Mission)
本框架是 **Meta-Partner (AI 飞轮元伙伴)** 孵化、评测与演进所有领域 Partner/Skill 的**底层因果认知模型**。
以**“实事求是·解放思想·知行合一”**为最基本、最核心的做事的姿势；以**“定性定量、科学类比、假设驱动、提炼建模”**为实现无限进步的四项方法；依托四大配套基础设施持续摘果子，实现跨周期复利演进。

---

## 2. 底层因果模型 1.2 (The Causal Model)

```
[核心做事姿势：实事求是 · 解放思想 · 知行合一 (Core Posture)]
                           │
       ┌───────────────────┴───────────────────┐
       ▼                                       ▼
[里程碑纪律：STEPS 严格顺序依赖 (S->T->E->P->S)]  [推进引擎：实现无限进步的四项方法]
       │                                       │
       │  1. S (Scope) 确定重要独立单元           ├─ 1. 定性定量 (事实真实证据)
       │  2. T (Target) 确立可证伪目标          ├─ 2. 科学类比 (经典理论框架)
       │  3. E (Element) 建立因果框架 1.0        ├─ 3. 假设驱动 (假设库快速验真)
       │  4. P (Predict) 启动四方法迭代          └─ 4. 提炼建模 (闭环因果模型升级)
       │  5. S (Support) 落地四大配套                   │
       ▼                                               │
[支撑底座：四大配套基础设施 (S: 实验探针 / 调研框架 / 假设库 / 闭环模型)] ◄──┘
```

### 核心因果断言 (Causal Assertions):
1. **输入决定幻觉率**：问题的 Scope 越模糊，LLM 的输出越倾向于“伪深刻”与谄媚赞同；必须下拆 2~5 层找到最小关键独立单元。
2. **目标决定检验度**：无法定量的目标无法证伪，无法证伪的目标会导致迭代方向失去坐标；必须坚持 Top 1 主指标 + N 辅指标。
3. **框架决定认知深度**：没有 1.0 框架，所有的所谓迭代都是碎步乱撞；1.0 粗糙没关系，但因果逻辑必须显式闭环。
4. **核心姿势统领律**：实事求是（事实第一）、解放思想（破除局限）、知行合一（落地保障）是最底层的做事姿势。违背此姿势，任何方法论都会退化为形式主义。
5. **四方法无限进步律**：定性定量、科学类比、假设驱动、提炼建模是**持续迭代的方法武器**。遇到任何复杂卡点，立即用这四项方法进行推演攻坚，不断摘果子。
6. **配套决定存活律**：四方法绝不能靠意志力空转，必须在底层建立对应的基础设施：
   - 定性定量必须配**【定性定量实验探针】**；
   - 科学类比必须配**【经典调研工具框架】**；
   - 假设驱动必须配**【假设库与证伪单】**；
   - 提炼建模必须配**【闭环演进的因果模型底座】**。

## 3. 四大配套基础设施规范 (The 4 Support Infrastructures)

所有 Partner（包括 Meta-Partner 自身及生产出的子 Partner），必须在自身架构中配齐这四大基础设施：

| 基础设施 (Support Infra) | 对应四方法 | 物理落盘载体 | 核心职责与运作机制 |
| :--- | :--- | :--- | :--- |
| **1. 实验探针 (Telemetry Probes)** | 定性定量 (事实) | `scripts/` (PEP 723 CLI) + `state/` | 真实客观数据采集器。拒绝盲目人肉翻找，用探针在 10 秒内抓取环境真相（日志、文件大小、耗时、调用栈）。 |
| **2. 经典调研框架 (Research Framework)** | 科学类比 (理论) | `references/` (经典理论库) | 领域经典模型沉淀。遇到业务卡点，立刻拉出经典调研模板进行外部标杆比对与科学类比，不闭门造车。 |
| **3. 假设库与证伪单 (Hypothesis Ledger)** | 假设驱动 (假设) | `state/hypotheses.json` | 显式管理不确定性。记录：假设命题、验证手段、最小探针成本、证伪条件、当前状态 (PENDING / VALIDATED / REFUTED)。 |
| **4. 闭环模型底座 (Closed-Loop Model)** | 提炼建模 (建模) | `FRAMEWORK.md` (版本化) | 随着四项方法持续吸收事实与理论，定期把有效规律沉淀为版本化的因果图谱，指导下一次循环。 |

## 4. STEPS 里程碑生产流水线 (Milestone Pipeline)

每一个 Partner 的孵化，必须顺序穿过 5 个扎实的里程碑，严禁前置不牢而跳步：

| 里程碑 | 核心产出 (Deliverable) | 准出硬门禁 (Done When / Gate) | 违背的因果惩罚 |
| :--- | :--- | :--- | :--- |
| **S · Scope** | 确定重要/困难/重复的高复用难题，下拆 2~5 层至“以小撬大”独立单元 | 450 字符以内负向排除边界明确 (`DO NOT TRIGGER when`) | 凡事都 Y，任务泛化，被垃圾输入击穿 |
| **T · Target** | 确立 Top 1 核心主指标 + N 辅助指标 | 具备明确退出态与可证伪度量公式（非形容词） | 无法证伪，无法判断何时交付完成 |
| **E · Element** | 勇敢建立因果认知框架 1.0（3~7 个要素） | 输出显式因果推导链，能解释“为什么这么做” | 框架缺失或过细低效，沦为常识拼凑 |
| **P · Predict** | 启动无限进步四方法（定性定量、科学类比、假设驱动、提炼建模）推演 | 必须输出 Track 2 四轴盲区雷达，指明 V0.2 选项 | 只会一叉，迅速卡死在经验或理论盲区 |
| **S · Support** | 装配四大基础设施（实验探针、调研框架、假设库、闭环模型） | 探针实测 PASS + 假设库初始化 + 门禁校验满分 | 知行脱节，会话一关资产即废，支持失忆 |

## 5. 定量度量评估体系 (Metrics: Top 1 + N)

### 🏆 Top 1 核心主指标：一次交付收敛率 (First-Pass Convergence Rate, FPCR)
$$\text{FPCR} = \frac{\text{首次即满足验收条件且无运行时错误修复的 Partner 数量}}{\text{总创建数量}} \ge 85\%$$

### 📊 N 个辅助支撑指标：
1. **静态契约合规率**：`validate_artifact.py` 静态评分稳定保持在 **100.0 分**。
2. **前缀漂移率 (Drift Rate)**：`check_persona_drift.py` 判定稳定为 **PASS (Drift = 0)**。
3. **确定性算力转移比**：确定性逻辑转移至 Python 探针脚本的占比 **$\ge 80\%$**。
4. **四大配套完备度**：探针工具、调研库、假设库、闭环模型 4 项在位率 **100%**。
